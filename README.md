Alocação de Alunos em Escolas Municipais
Projeto desenvolvido em Python como Trabalho de Graduação do curso de Ciência de Dados.

Objetivo
Desenvolver um modelo de programação linear para alocar alunos em escolas municipais de Cajamar e Santana de Parnaíba (SP), buscando minimizar as distâncias entre as residências e as unidades escolares, respeitando a disponibilidade de vagas.

Tecnologias utilizadas
Python

Pandas e NumPy

Geopy (ArcGIS)

OSRM

Docker

SciPy

Streamlit

Estrutura do projeto
Os códigos estão organizados por etapas, incluindo:

Preparação e tratamento dos dados escolares;

Geocodificação dos endereços;

Cálculo das distâncias;

Modelo de programação linear para alocação dos alunos;

Interface para apresentação dos resultados.

Dados utilizados
Foram utilizados dados do Censo Escolar 2025 (INEP) e dados sintéticos de alunos para os testes do modelo.

Observação
Antes de executar os códigos, é necessário ajustar os caminhos dos arquivos, diretórios e locais de download conforme a estrutura de pastas e o ambiente de cada computador.
